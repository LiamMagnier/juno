# Changelog

All notable user-facing and architectural changes to Juno will be documented in this file.
The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.1.0/),
and this project adheres to [Semantic Versioning](https://semver.org/spec/v2.0.0.html).

## [1.9.3] - 2026-10-01

### Added
- **Agents Redesign:** Live avatar presence, unified one-column team view, and calm profile inspection across Web, macOS, and iOS.
- **Account Remote MCP:** Support for user-scoped remote MCP connectors with OAuth token discovery and automated tool registration.
- **SKILL.md Import:** Direct import of agent skill definitions with frontmatter and bundle archiving validation.
- **Code Thinking Channel:** Dedicated streaming thinking and reasoning channel for agent and coding sessions.

### Fixed
- Compact phone cards and busy-indicator states in native clients.
- Fresh thread creation payloads and panel toggling behavior.

## [1.9.2] - 2026-09-28

### Added
- macOS soft-UI refinements and unified window controls.
- Voice mode fallback and audio streaming stabilization over WebSocket relay.

### Fixed
- Fixed Gemini thinking stream handling and thinking level budget mapping.
- Chat retry clearing behavior and prompt regeneration states.

## [1.9.1] - 2026-09-27

### Added
- iOS widgets and Live Activities for background code runs and research sessions.
- Screenshot capture tool hardening with anti-repetition hashing.

### Fixed
- Model selector provider group rendering and effort ladder validation.

## [1.9.0] - 2026-09-27

### Added
- Full deep research and canvas report document view.
- Stage B native snapshot testing and Swift-TypeScript capability contract enforcement.

## [1.6.0] - 2026-09-23

### Added
- Native macOS and iOS client integration foundation.
- Synchronized chat wire contract and cryptographic message encryption at rest.
