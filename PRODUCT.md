# Juno

<!-- impeccable:product-schema 1 -->

## Platform

adaptive

## Users

People using Juno on the web and macOS to delegate personal and professional work to persistent AI agents. These platforms were explicitly confirmed by the user.

## Product Purpose

Juno combines conversations, connected tools, reusable skills, voice, and coding workspaces. Agents are persistent teammates with a conversation, a brief, goals, memory, routines, and permission-bound tasks.

## Operating Context

The web application is Next.js/React; native clients use SwiftUI. Agents share the existing authenticated server and Work execution layer. Computer access depends on configured infrastructure. Conversations and account resources remain scoped to their owner.

## Capabilities and Constraints

The user requires Agents to begin and configure themselves through conversation without a hiring questionnaire. Rebuild the entire Agents interface, identity shapes, customization, and motion for web and Mac. Preserve task execution, approvals, costs, cancellation, ownership, and durable history. Production readiness requires meaningful regression and integration evidence, not preview screenshots alone.

## Brand Commitments

Juno is the product name. The confirmed direction is quiet, premium, sleek, and modern. The user names Grok Bot, ChatGPT, and Meta Muse as interaction and craft references, and requests restrained blur/glass treatment. These references do not authorize copying vendor artwork or claiming capabilities Juno does not implement.

## Evidence on Hand

Existing authenticated APIs, domain tests, native fixture snapshots, and working development galleries. `docs/juno-workspace-upgrade.md` records the preceding refinement and its evidence limits. Preview sample goals and activity are illustrative data, never a newly created agent's real work.

## Product Principles

- Conversation is the entry point and configuration mechanism.
- Start useful work from a clear request; ask only for blocking information.
- Identity and status are legible without constant decoration.
- Explain actual activity and preserve user control over consequential actions.
- Keep web and native behavior consistent while respecting platform conventions.
