# Alevr Chat — conversation design system

Working specification · 2026-10-01. Read with BRAND_IDENTITY.md and NAMES_AND_ICONS.md. Image: assets/alevr-chat-system.png.

## Purpose and distinction

The everyday conversation product: answer, research, make something and carry out work from one place. Chat is the quietest expression of the identity. Its visual signature is editorial serif display, neutral composition, a centered context-aware composer and clear output. Mathematics is expressed through the Open Fold mark and precise geometry; cosmic diagrams belong to identity presentation rather than conversation wallpaper.

## Components and hierarchy

| Surface | Design contract |
|---|---|
| Desktop shell | V3 frame, 8 px panel inset, 14 px radius; sidebar on the frame; content on Ground |
| Navigation | Chat/Code workspace controls; New chat, Search, Projects, Library, Customize; Orbit agent section and Recent |
| Home | Upright Newsreader greeting, centered no-shadow composer; sparse relevant suggestions only |
| Composer | 22 px radius, tonal field and crisp edge; semantic context tokens embedded in the sentence; meaningful Add/Mic/Send controls |
| Transcript | Readable measure, restrained user-turn surface, no heavy assistant bubble; visible real work and readable receipts |
| Work and research | Appear within conversation; plan may be reviewed/edited before running; no forced switch to an extra branded mode |
| Approval | Explicit action, target, scope and consequence; deterministic existing approval behavior |
| Artifact | Finished output opens as a useful document/design/file; Library retains it |
| Floating UI | Restrained translucent material with solid fallback; never blur the full content plane |
| Phone | Full bleed, one conversation focus, keyboard-aware composer and accessible controls |

Keep functionality and state truthful: copy feedback, generation Stop, actual upload progress, retry recovery and completion receipts. Loading starts from actual events; a branded animation never decides success.

## Typography, color and rhythm

Inherit all exact shared V3 values. Newsreader owns the greeting and sparse display moments; Inter carries every operational label and answer body; JetBrains Mono is reserved for code/technical data. Graphite is the primary active control treatment. Ultramarine is a small live/focus presence, not a broad button repaint. Attention remains readable words. Dark uses charcoal surface steps and subdued blue, not pure-black panels with bright-white paragraphs.

Spacing favors continuous reading and a calm composer. Rounded token geometry remains smaller than container geometry. Do not introduce a separate warm-paper palette, an italic personal-name greeting, a hero gallery inside the application or a starfield behind the transcript.
