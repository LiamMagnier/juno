# Alevr Orbit — agent design system

Working specification · 2026-10-01. Read with BRAND_IDENTITY.md and NAMES_AND_ICONS.md. Image: assets/alevr-orbit-system.png.

## Purpose and distinction

Persistent named agents carry work forward around shared context. Orbit is the expressive agent product within Alevr: the mathematical/cosmic design direction is strongest here. An open ellipse and measured trajectories explain relationships and continuity. The working interface stays conversation-led and makes control, progress and evidence immediately legible.

The vocabulary is Alevr Orbit in explanatory copy, Orbit in navigation, Your agents as the descriptor, and agent for an individual. Never call an agent an Orbit. A user's agent name takes priority during work.

## Component system

| Component | Design contract |
|---|---|
| Workspace | Shared framed V3 shell and token system; persistent agent thread with operational side panel |
| Agent list | Named agents, compact face, role and readable current state; attention words only when a response is needed |
| Agent thread | Serif agent name, context-aware conversation, visible real progress and finished artifacts |
| Peek band | One restrained large character when meaningful; background material tuned to stay legible without a colored haze |
| Creation | Start by talking about the agent's work; capture role/instructions/standing work through conversation; explicit review |
| Profile and permissions | Clear role, connected apps, Allow/Ask first/Block decisions, budget/schedule/computer controls where supported |
| Appearance editor | Shape, color, graphic-eye style and accessory choices with large live preview; lightweight sprite thumbnails |
| Activity | Chronological real events, approvals and receipts in context; no invented orbital progress diagram |
| Computer / handback | Real view and clear control boundary; state says who controls the computer |
| Empty state | Explain what an agent can carry forward and offer Create agent; no decorative gallery as the primary product |

## Shape and material family

The latest source authority is DECISIONS D-034, refining D-031–D-033. Build an original set of flocked designer toys: short velvet surface, crisp silhouette, saturated controlled body colors, flat graphic eyes, no mouth/blush/animal realism. Prefer distinct soft geometric bodies over variations of the same blob. Accessories are optional, bold matte forms and independent from role.

The generated board's characters are exploration. They do not replace the unapproved Blender work or the existing shipped faces. Later implementation needs approved meshes/materials, glb/USD projection where applicable and a consistent serialization/configuration contract; raster illustrations do not supply that rig.

Color belongs to the agent's identity and occasional contextual tint. The product's default shell stays neutral. Agents do not become planets; users should choose a role and appearance without space lore. Existing user agent names remain unchanged.

## Runtime states and motion

| State | Words | Visual support |
|---|---|---|
| Ready | Ready | Stable neutral pose |
| Thinking | Thinking | Brief meaningful eye/pose event; no perpetual spinner |
| Working | Actual action, or Working | Restrained activity support from actual events |
| Waiting | Needs your answer | Attention-colored words; still/expectant pose |
| Blocked | Blocked, plus reason | Clear recovery text; no alarming decorative badge |
| Finished | Finished, plus output | Brief settling gesture, then still |

No state is inferred from color or pose alone. At 28 px and below, cached sprites. One shared renderer; large preview on demand, hidden work stops. A subtle idle may exist only for the visible large thread character and stops with Reduce Motion. Use the inherited motion values; do not turn orbit trajectories into constant loading effects.

## Cosmos and mathematics

Primary graphic: separated elliptical arcs, a measured path and purposeful negative space. On a brand board or introduction, an orbital construction shows shared context and independent paths. In an actual data diagram, positions/connections must reflect real relationships. Do not imply meaningful coordinates with decorative equations.

Orbit owns the more expressive charcoal cosmic panel in the identity presentation, framed by the same neutral V3 UI and blue. No neon galaxy, starfield UI background, rocket metaphor for approvals or mission terminology for ordinary actions. The cosmic direction adds meaning to the brand rather than extra things to learn.

## Outputs and review

Continuum is the selected master mark; the Orbit arc glyph remains secondary. The current board retains the mathematical/cosmic character and component direction. Apply MOTION_AND_THINKING.md to truthful agent state, handoffs and thinking, preserving readable words and D-034 character rules. Final character/production-artwork approval remains separate.

The separate Orbit board demonstrates master/submark lockup, construction, working thread, character family, customization, readable states, conversation-first creation and semantic glyphs. Acceptance later requires real creation/conversation/permissions/standing-work/attention/completion flows, original approved characters and native projection. Neither the board nor this specification certifies runtime capability or cross-platform acceptance.
