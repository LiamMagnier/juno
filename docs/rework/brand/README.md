## Authority and status

- **Latest owner decision:** Continuum is selected as Alevr’s master-logo direction. The A-shaped Open Fold is rejected and archived. Current images are being reprojected consistently; the owner also requested branded thinking and premium micro-interactions across every feature. The motion brief records those behaviors; it does not implement them.
- For the proposed identity, this package supersedes older advice to keep Juno or use Crew as the collective label. Historical audits, dated release records, third-party names and source identifiers remain intact.
- V3 source values and DECISIONS D-027–D-034 remain the foundation. The proposed brand does not restart the stopped implementation or replace its existing faces.
- Inherited: palette, fonts, framed shell, composer geometry, custom-icon grammar, event-driven motion, conversation-first agents and deterministic approvals.
- Proposed: Alevr spelling/pronunciation, Orbit hierarchy, orbital submark and the controlled mathematical visual world. Continuum is the selected master logo; Open Fold was rejected.
- Generated boards are visual concepts. The written values govern exact implementation; generated lettering and pixel geometry are illustrative.
- Pending: name availability decision, final artwork review, vector masters, favicon and platform-size exports, native projection and authenticated cross-platform acceptance. No release claim is made.
