# Full product review — 2 September 2026

The review that preceded the Soft UI redesign (`SOFT_UI.md`). It covers the
website, the iOS app and the macOS app, measured against ChatGPT (web, iOS,
macOS), the Codex app and Codex remote control, Claude Code, the Claude apps,
T3 Code and ZCode. Findings are the state **before** the redesign; the
"Resolution" column says what the redesign did about each one.

## Website

| # | Finding | Resolution |
|---|---|---|
| 1 | `docs/JUNO.md` §3 described a design system that no longer existed (Newsreader, `ease-spring`, `.sheen-sweep`, 24px radius). | §3 rewritten from the live tokens. |
| 2 | Dark theme was true black, so no dual-shadow depth could read. | Dark ground moved to warm charcoal `30 7% 9%`; depth kit `--neu-*` with raised / inset / float / pressed. |
| 3 | A `.neumorphic-*` scaffold existed unused, with an undefined `--radius-xl`. | Deleted; replaced by `.surface-raised/-raised-lg/-inset/-float`, `.control-neu/-primary`. |
| 4 | Undefined utilities emitting nothing: `shadow-xs` ×15, `rounded-row` ×3; `.composer-surface` dead paint under raw rgba overrides. | All removed; composer shell is a real raised surface with an inset field. |
| 5 | Four radii and three materials for one floating tier (dialog 18, popover 12, toast 14, sheet 0). | One ladder: control 10 · field 12 · menu 14 · card 16 · panel 20. |
| 6 | Ten off-system surfaces (settings modal, library picker, model picker, composer popover with `#161618`, code/new, connectors menu, session composer, profile, context inspector, canvas toolbar). | All on the shared surfaces. |
| 7 | Settings existed twice (page with six scroll-spy groups; modal with seven tabs re-rendering the page with `hideHeader`/`filterGroup`). | One `SettingsModal` with nine sections; `/settings` renders the same sections. |
| 8 | Five page measures (`max-w-2xl…6xl`), Work had its own page frame. | `AppPage measure="reading|wide|full"` + `AppPageHeader` everywhere. |
| 9 | Folders and archive existed in the API and types but had no UI. | Sidebar folders, move-to-folder, archive/restore, "Archived chats" sheet. |

| 11 | `transition-all` ×53, raw `duration-*`, `uppercase` eyebrows, `aura-preview` shipping to production, two python patch scripts at the repo root. | Scoped transitions, ladder durations, sentence case, guarded preview, scripts deleted. |
| 12 | A sync-stream `router.refresh()` remounted the chat after the first reply (URL rewritten to `/chat/<id>` while `/chat` stayed mounted). | Refresh deferred while the URL is soft-routed; covered by `e2e/chat.spec.ts`. |

## macOS

| # | Finding | Resolution |
|---|---|---|
| 1 | Code sidebar showed six equal-weight sections; Settings/Usage/Connections rendered inside the coding column. | Sessions column grouped by project with status, time, branch, diff stat and All · Running · Needs you · Done; account pages open in the Settings window. |
| 2 | Three "start a task" entry points that behaved differently; the repo shown in four places. | One New task screen: project row, glass composer, Environment / Permissions / Model + effort, four starters. |

| 6 | Parallel motion ladder `DesktopChatMotion`, three reading measures, duplicated inspector metric, two product switchers, seven dead files. | One `JunoMotion`, one `JunoReadingMeasure`, one switcher with Chat · Code · Work, dead files removed. |
| 7 | A half-finished edit had the tool scheduler return placeholder results (tools never ran). | Restored delegation `AgentOrchestrator.executeToolCall → ToolScheduler.executeCall`; `scripts/check-approval-dispatch.mjs` now verifies hook → authorize → execute order in the scheduler. |

Open: the tonal soft-UI pass on Library / Artifacts / Connections / Tasks /
Usage / Memory pages; screenshot capture needs a manual run with the system
picker; the target-size ratchet sits at 351 (was 410).
