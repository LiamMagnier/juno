Precise Power

One floating command surface for every list of choices, 32px rows with a fixed shortcut column, a composer whose tools sit inline and whose primary disc is always the strongest object, and motion that settles in 70 to 160ms. Web, macOS and iOS share the same layout and vocabulary; each renders it natively.

  • 01Click everything. Menus open, submenus open on 100ms hover intent with a safe triangle, dialogs, sheets and toasts are live, and send morphs to stop.
  • 02Keyboard first. Every live menu supports ↑↓ (wrap), Home/End, →/← for submenus, ↵, Esc and type-to-filter.
  • 03Slow motion 4× multiplies every duration and draws the submenu safe triangle, so each motion step can be inspected.
  • 04Light and dark side by side on every board; at phone width the board shows the theme that matches your system.
A

Foundations

4px spacing, a concentric radius ladder (container 12 → inset 4 → item 8; composer 20 → 8 → 12), three hairlines, four elevation levels where dark mode lifts by lightening the surface, one chrome type size (13/20), and one state ladder.

B

Icons

One family drawn on SF Symbols geometry: 24-unit canvas, 20-unit live area, round caps and joins, line 1.25 / 1.5 / 1.75px at the 14 / 16 / 20 optical sizes, outline at rest and filled only for a persisting on-state. Each glyph maps 1:1 to an SF Symbol on native.

C

Components

Every 28–36px control shares radius 8; primary has no shadow and a real hover tone; disabled is a quiet fill, never an opacity; selected is a fill one rung deeper plus weight 500.

D

Menus — one command surface

Radius 12, inset 4, 32px rows, one trailing slot (shortcut, chevron, check or value), search on any list longer than seven, instant highlight with a keyboard ring. The model picker, +, / and ⌘K are the same component at widths 320, 272, 320 and 560. Use the live strip at the bottom of each board.

E

Pop-ups

Dialogs are a three-row grid with pinned chrome (confirm 400 · form 520 · workspace 720), destructive confirms are alert dialogs with Cancel focused, toasts stack three deep above the composer, and hover cards open on 300ms intent.

F

Composer

Radius 20, inset 8, every control 32×32 at radius 12 (concentric), one 16px glyph size, the tools row inline. The primary disc is always ink: waveform when empty, arrow when there is text, square while streaming. Drawn at 600px here; it ships at min(720px, 100% − gutters).

F′

Mobile web — 390

Same composer with 36px controls in 44px hit areas; + opens a bottom sheet with a grabber, medium and large detents, search and 48px rows. Drag the sheet on the right-hand phone.

G

Motion — step by step

Every bar is one step: property, from → to, duration, curve and delay, drawn on a 0–480ms axis. Press ▶ to run the step timeline on its specimen; slow motion multiplies every value by four. Entrances: --ease-snap cubic-bezier(.25,1,.5,1). Exits: --ease-in on the rung below. No new duration rung.

I

Native — macOS 26 and iOS 26

Same layout and vocabulary as the web. Liquid Glass only on the control layer that floats above content (toolbar, sidebar, floating composer bar, system menus); messages and cards stay opaque. SF Symbols, system Menu, Picker, confirmationDialog and sheets. Glass here is approximated with gradients and a backdrop blur, in this mockup only.
