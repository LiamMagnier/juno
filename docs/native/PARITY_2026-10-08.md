# Native parity audit — 2026-10-08

What the website (Alevr, code name Juno) has that the Mac app (`native/macOS/JunoDesktop`) and the iPhone app (`native/iOS/JunoMobile`) do not, after three weeks of web work (`git log --since=2026-09-15 -- src/`: 652 commits). Built from a read of the current tree and that history, not from the generated ledger alone (`PARITY_MATRIX.md`, which marks several pages Native that are really Partial; corrections at the end).

Statuses: **Native** (at web parity), **Partial** (exists with the gap named), **Missing**, **n/a** (by decision). The last column says what branch `polish/native-parity` did about it; see [What this branch changed](#what-this-branch-changed).

Base already on this branch before the audit (2026-10-08, not redone here): galaxy working mark, paced streaming with fresh words fading in, eased transcript follow, the Alevr Continuum mark and wordmark, and the native Deep Field research redesign.

## Design language (the biggest single gap)

The web moved to a new language on 2026-10-02/03 (Alevr V3 foundation, editorial kit, "Revamp in the homepage's language"). The native apps kept the earlier one.

On 2026-10-08 the owner asked for a ChatGPT-grade native redesign instead of a port of the web's look; a separate design lane owns the shell, composer, home and message rows (spec: NATIVE_REDESIGN_SPEC.md). ## Ranked gaps (daily-use value)

Mac first, then iOS.

1. The design language: serif page titles, the construction (home field, page backdrops, covers), the new greeting, Alevr naming, no pills.
2. Semantic artifacts render as raw JSON in chat.
3. Model chip flow (catalogue first for models without effort; one chip on iOS).
4. Project folders and the projects grid.
5. Memory redesign, skill candidates, provenance, clear project memory.
6. Library "Made by Alevr" and deleted artifacts with restore; artifact duplicate and download.
7. Profile and username.
8. Customize › Apps rows, detail sheet, standing grants.
9. Auto receipt, transcript rail, breadcrumb, clarification card, media params tray.
10. iOS: notifications inbox, Skills, Routines, account security, find in conversation, tool rows.

## Ledger corrections (`contracts/parity/features.json`)

- `/library`, `/memory`, `/customize`: marked Native on both apps; Partial on both (see above).
- `/api/artifacts/[id]/publication`: listed as Native; only the iPhone reads it.
- `/api/profile/stats`: Planned, but no web caller remains (`/activity` replaced it).
- `/api/prompts`: Planned, but the web has no surface either.
- `/upgrade`: the Mac sells monthly and yearly; the iPhone ships a StoreKit plans sheet.
- `/api/stripe/cancel`: "App Store" does not apply to the Mac, which subscribes through Stripe.
