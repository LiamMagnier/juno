## What shipped on the branch

- **Exercise card** (`JunoDesignSystem/LiveUI/JunoLiveUIExercise.swift`, parsed
  in `JunoLiveUISpec.swift`, aliases practice/question/answer, up to 5 hints, no
  solution ever kept). Title + tag, statement with `**bold**`/`` `code` ``, an
  answer box (monospace when the exercise names a language, sized to its lines),
  hints one at a time, Run for JS/TS/Python/SQL, Send answer posting
  `**{title}**\n\n{answer}` (fenced in its language when code), then
  "Sent for correction". ⌘↩ sends. Mac sends through the Live UI host's
  `onPrompt` (already a send); iOS gets a new `JunoLiveUIHost.onSend` that sends
  the turn straight away (`sendLiveUIAnswer` in JunoMobileConversationsView).
  Shared fixture case in `contracts/live-ui/fixtures/spec.json`, held by
  `tests/live-ui.test.ts` and `LiveUIFixtureTests.swift`.
- **Run on code blocks** (`JunoDesignSystem/JunoCodeRun.swift`), on both the
  standard block (`JunoAIcssCodeBlock`, the iPhone's) and the reading block
  (`JunoProseCodeBlock`, the Mac's). The app asks `POST /api/code/console`
  (new, `src/app/api/code/console/route.ts`, authenticated, rate-limited, no
  execution server-side) for the web's own inline console document, built by
  `src/lib/sandbox/console-doc.ts` (moved out of `sandbox-frame.tsx` unchanged so
  a route can import it), and runs it in a WKWebView: non-persistent store, nil
  base URL, no navigation, no popups, a content-rule list that only lets
  jsdelivr / unpkg / PyPI through, one message handler for height and state.
  Output header "Output" / "Output · SQLite, HR sample", state in words, Run
  again / Close. Server languages (C, Java…) have no Run (prod has no exec host).
  Client: `JunoChatKit/NativeCodeConsoleClient.swift`; the Mac
  (`DesktopChatWorkspace`) and iOS (`JunoMobileConversationsView`) hand the
  runner down as `junoCodeRunner`.
- **VS Code token colours** in `JunoSyntaxHighlighter` from
  `JunoGeneratedTokens` (`--code-keyword`, type, function, string, number,
  comment; Light+ / Dark+). SQL keywords match in any case, SQL functions and
  types are teal, calls take the function ink.
- **Declared** `live_ui_exercise` and `code_run` in
  `NativeChatClientFeatures.declared` (tests updated).
- Parity: `/api/code/console` classified `native`; PARITY_MATRIX regenerated.
- Controls: Run is a glass capsule (`.junoGlass` on the Mac, `.glass` capsule on
  iOS), Send answer the prominent glass in the accent (`.junoProminent` /
  `junoProminentAction()`), icon-only keys round; website icons only.
  The glass ratchet was re-recorded once on purpose for these capsules.
